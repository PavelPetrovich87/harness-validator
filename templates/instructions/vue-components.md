# Vue SFC Guidelines

- Use `<script setup>` for cleaner composition API.
- Keep template logic minimal; use computed properties.
- Extract reusable composables into `composables/` directory.
- Use TypeScript for prop definitions and emits.
- Prefer scoped styles or CSS Modules.
